## 4. 典型用例详述

### UC-B-06 结算

- **参与者**：成员
- **描述**：系统计算每个成员的净余额，生成欠款关系，成员完成转账后标记已还。
- **前置条件**：账本中已有支出记录。
- **后置条件**：欠款状态更新为已还，余额重新计算。
- **主流程**：
  1. 成员进入结算页；
  2. 系统计算每人应付、垫付和净额；
  3. 系统展示“谁欠谁多少”；
  4. 欠款人线下转账；
  5. 欠款人点击“已还”；
  6. 系统更新状态。
- **异常流程**：
  - 记录被删除后余额变化：系统重新计算（未说明已还状态如何处理）。
