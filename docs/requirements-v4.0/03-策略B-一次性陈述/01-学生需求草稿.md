# 策略 B · 学生需求草稿（一次性输入）

> 这是学生在**没有经过访谈澄清**的情况下，凭直觉写下的全部需求。
> 保留原始口语、矛盾与遗漏，作为策略 B 的输入基线。

## 我的想法

我想给现在的记账软件加一个“共享账本”，主要是宿舍和社团用。现在大家都是在群里发红包，然后一个人用 Excel 记，月底算账很麻烦。

我想到的功能：

1. 可以创建账本，把室友拉进来，发个链接就能加入；
2. 每个人都能记账，记金额、分类、日期、谁付的钱、谁参与；
3. 可以 AA，也可以按比例或者按金额分；
4. 系统自动算谁欠谁；
5. 结算后能标记已还；
6. 账本里能看统计，也能导出；
7. 记录可以删，谁都能删，简单一点；
8. 成员可以随时退出；
9. 可以设预算；
10. 要有提醒；
11. 数据要安全，只有成员能看；
12. 最好能自动导入支付宝/微信账单，能识别小票，能语音记账。

## 我觉得需要但没想清楚的点

- 邀请链接要不要过期？我没想好，最好永久有效，省得麻烦；
- 删除记录要不要留痕？大家都这么熟，应该不用吧；
- 退出的时候如果有欠款怎么办？先退了再说，反正账还在；
- 预算超了提醒谁？提醒所有人吧；
- 需不需要管理员？先不要，创建者一个人管就行；
- 统计要看哪些维度？总额和分类吧，其他的以后再说。
