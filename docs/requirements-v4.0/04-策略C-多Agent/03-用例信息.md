# 策略 C · 用例信息（多 Agent 输出）

## 1. 参与者

| 参与者 | 类型 | 说明 |
|---|---|---|
| 访客 Guest | 主动 | 未登录或未加入账本 |
| 普通成员 Member | 主动 | 账本参与者 |
| 管理员 Admin | 主动 | 由 Owner 授权，管理普通成员和账目 |
| 创建者 Owner | 主动 | 账本所有者，最高权限 |
| 系统 System | 被动 | 计算分摊、余额、提醒、审计 |

## 4. 典型用例详述

### UC-C-05 管理成员与角色

- **参与者**：Owner、Admin
- **描述**：Owner 设置或撤销管理员、移除成员、转让创建者；Admin 移除普通成员。
- **前置条件**：操作者具备对应权限；账本未归档。
- **后置条件**：成员角色或成员关系变更；变更写入审计日志；被移除者立即失去访问权。
- **主流程**：
  1. 进入成员管理页；
  2. 选择目标成员和操作（设为管理员/撤销管理员/移除/转让）；
  3. 系统校验操作者权限和目标成员角色；
  4. 二次确认；
  5. 执行变更并刷新成员列表。
- **异常流程**：
  - Admin 尝试移除 Admin 或 Owner：拒绝；
  - Owner 尝试移除自己：提示使用转让或注销流程；
  - 被移除成员余额不为 0：转由 Owner 承接，并记录原因。
