# 策略 A · 用例信息（访谈式输出）

## 1. 参与者

| 参与者 | 类型 | 说明 |
|---|---|---|
| 访客 Guest | 主动 | 未登录或未加入账本的用户 |
| 普通成员 Member | 主动 | 已加入账本的成员 |
| 账本管理员 Admin | 主动 | 由创建者授权，可管理普通成员和账目 |
| 账本创建者 Owner | 主动 | 账本最高权限持有者 |
| 系统 System | 被动 | 计算分摊、余额、提醒和审计 |

|---|---|---|---|

## 4. 典型用例详述

### UC-A-06 记录共同支出

- **参与者**：普通成员
- **描述**：成员记录一笔多人共同支出，指定付款人、参与人和分摊方式。
- **前置条件**：用户已登录且是账本成员；账本未归档。
- **后置条件**：支出记录创建成功；每个参与人的应付金额已计算；账本余额更新。
- **主流程**：
  1. 成员点击“记一笔”；
  2. 输入金额、选择分类、填写备注和日期；
  3. 选择付款人（默认自己）和参与人；
  4. 选择分摊方式，系统实时显示每人应付；
  5. 可选上传凭证；
  6. 提交，系统校验金额与分摊；
  7. 保存成功，流水和余额刷新。
- **异常流程**：
  - 金额 ≤ 0 或超过两位小数：拒绝保存；
  - 参与人为空或不是成员：拒绝保存；
  - 分摊合计不等于总额：提示差额，拒绝保存；
  - 日期晚于今天或早于一年前：拒绝保存。
